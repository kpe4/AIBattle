# Мини‑платформер на HTML/CSS/JS

## Введённый промпт
создай простую игру платформер на html / css / js - лимит 200 строк вообщем

## Ответ нейросети
Нейросеть предоставила минимальный рабочий платформер:

- Игрок (квадрат)
- Платформы
- Гравитация и прыжки
- Коллизии с платформами (включая удар головой и боковые столкновения)
- Управление стрелками ← → ↑
- Код укладывается примерно в 200 строк.

**Проблема:** при одновременном нажатии стрелки вверх и влево/вправо игрок «телепортируется» в исходную точку из-за использования `getBoundingClientRect()` для коллизий.

**Решение:** фиксирование координат контейнера:
const gameRect = game.getBoundingClientRect();
После исправления прыжки + движение работают корректно.

Нейросеть предложила дальнейшие улучшения: анимации, врагов, сбор монет, прокрутку камеры, уровни.
