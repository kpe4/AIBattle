# Отчёт по нейросети: Perplexity AI

## Использованный промпт
создай простую игру платформер на html / css / js - лимит 200 строк вообщем

Дополнительные уточнения в диалоге:
- сделать всё в одном HTML файле
- добавить платформы и коллизию
- добавить движение вправо и влево
- сделать возможность удерживать кнопку движения

## Что выдала нейросеть
Нейросеть сначала создала простой платформер из трёх файлов: HTML, CSS и JavaScript.  
После уточнения она переписала код так, чтобы всё находилось в одном HTML файле.

В игре реализовано:
- игрок (красный квадрат)
- земля
- несколько платформ
- прыжок
- движение влево и вправо
- удерживание клавиш для постоянного движения
- простая проверка коллизии с платформами

Управление:
- стрелка вверх — прыжок
- стрелки влево и вправо — движение

## Анализ работы
Нейросеть в целом правильно поняла задачу и постепенно улучшала код после уточнений.

Код получился рабочий и достаточно простой. Платформы добавлены через HTML, а проверка столкновения реализована через `getBoundingClientRect()`.

Однако есть несколько проблем:
- код не проверяет границы карты (игрок может выйти за пределы поля)
- физика прыжка довольно простая и не очень точная
- коллизия работает не идеально и может давать баги
- код не оптимизирован (много `setInterval`)

Также изначально нейросеть не соблюдала условие одного файла и исправила это только после дополнительного запроса.

## Плюсы
- код достаточно понятный
- легко запустить (один HTML файл)
- постепенно добавляет функции по запросу
- реализованы основные механики платформера
- управление удержанием клавиш работает

## Минусы
- изначально не соблюдено требование одного файла
- простая и не очень стабильная физика
- коллизии могут работать неточно
- нет ограничения движения по границам
- структура кода не очень оптимальная

## Итог
Perplexity AI справилась с задачей на среднем уровне.  
Она смогла написать рабочий код платформера и постепенно улучшала его после уточнений.  

Однако код получился довольно простым и местами не очень аккуратным. Некоторые требования пришлось уточнять отдельно.
