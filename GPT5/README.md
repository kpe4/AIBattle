# Мини‑платформер на HTML/CSS/JS (Canvas)

## Введённый промпт
создай простую игру платформер на html / css / js - лимит 200 строк вообщем

## Ответ нейросети
Нейросеть предоставила минимальный рабочий платформер на **canvas**:

- Игрок (красный квадрат)
- Платформы (коричневые прямоугольники)
- Гравитация и прыжки (пробел)
- Коллизии с платформами
- Управление стрелками ← → и пробел
- Код укладывается примерно до 200 строк
- При падении ниже экрана игрок сбрасывается в стартовую точку

**Дополнительно:** нейросеть предложила простые варианты улучшений:
- Ускорение игрока (`speed:6`)
- Более высокий прыжок (`jump:14`)
- Изменить гравитацию (`gravity=0.7`)
- Изменить цвет игрока (`ctx.fillStyle="blue"`)
- Добавить новые платформы

Также возможны расширения:
- Добавление монет и врагов
- Камера, как в Mario
- Мини‑движок платформера (~200–300 строк)

## Анализ

**Плюсы:**
- Рабочий минимальный платформер с базовой физикой.
- Управление простое и интуитивное.
- Canvas даёт возможность легко улучшать графику.
- Код компактный и понятный, легко модифицируется.
- Возможность быстрого расширения: новые платформы, монеты, враги.

**Минусы / ограничения:**
- Очень базовая графика (квадратный игрок и платформы).
- Нет боковых столкновений, нет «удара головой» о платформу.
- Нет прокрутки уровня и камеры.
- Коллизии простые, могут некорректно работать при сложных движениях.
